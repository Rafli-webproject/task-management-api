# 🚀 Task Management API

API sederhana untuk mengelola daftar tugas (Task Management) yang dibangun menggunakan **Express.js** dan **TypeScript**. Proyek ini dibuat untuk memenuhi Tugas Day 1 Kelas XI RPL.

## 🛠️ Teknologi yang Digunakan
- **Node.js** (Runtime Environment)
- **Express.js** (Web Framework)
- **TypeScript** (Bahasa Pemrograman)
- **ts-node-dev** (Development Server)
